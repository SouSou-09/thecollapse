# TheCollapse

## 概要

**TheCollapse** は、プロキシブラウザ・履歴管理・アカウント機能を備えた Web アプリケーションです。  
Node.js をバックエンドとし、Docker による環境構築に対応しています。

---

## セットアップ

### Docker を使う場合

```bash
docker build -t thecollapse .
docker run -p 3000:3000 thecollapse
```

### ローカルで直接起動する場合

```bash
npm install
node index.js
```

---

## 機能一覧

| 機能 | 説明 |
|------|------|
| 🌐 プロキシブラウザ | モバイルChrome風UIによるプロキシ閲覧・タブ管理 |
| 🕘 閲覧履歴 | 過去のアクセス履歴を記録・確認 |
| 👤 アカウント | 個人データ管理・端末間でのデータ同期 |
| 🔄 履歴同期 | 複数端末・複数タブ間での履歴・ブックマーク同期 |

## Renderへのデプロイ

1. GitHubリポジトリ（`SouSou-09/thecollapse`）をRenderに接続する
2. Blueprint（`render.yaml`）を検出して自動構築：ビルド `npm ci --omit=dev` / 起動 `node index.js`
3. サーバーは `process.env.PORT` を参照するため、Render側でポート設定は不要
4. Docker（`Dockerfile` 同梱）でもそのまま動作します

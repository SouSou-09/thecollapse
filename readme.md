# TheCollapse

## 概要

**TheCollapse** は、プロキシブラウザ・履歴管理・アカウント機能を備えた Web アプリケーションです。  
Node.js をバックエンドとし、Docker による環境構築に対応しています。

---

## セットアップ

### Docker を使う場合

```bash
docker build -t thecollapse .
docker run -p 3000:3000 thecollapse
```

### ローカルで直接起動する場合

```bash
npm install
node index.js
```

---

## 機能一覧

| 機能 | 説明 |
|------|------|
| 🌐 プロキシブラウザ | モバイルChrome風UIによるプロキシ閲覧・タブ管理 |
| 🕘 閲覧履歴 | 過去のアクセス履歴を記録・確認 |
| 👤 アカウント | 個人データ管理・端末間でのデータ同期 |
| 🔄 履歴同期 | 複数端末・複数タブ間での履歴・ブックマーク同期 |

## Renderへのデプロイ

1. GitHubリポジトリ（`SouSou-09/thecollapse`）をRenderに接続する
2. Blueprint（`render.yaml`）を検出して自動構築：ビルド `npm ci --omit=dev` / 起動 `node index.js`
3. サーバーは `process.env.PORT` を参照するため、Render側でポート設定は不要
4. Docker（`Dockerfile` 同梱）でもそのまま動作します

## Fly.ioへのデプロイ

`fly.toml` と Docker の設定を同梱しています（東京リージョン・メモリ少なめの小型構成）。

1. `flyctl` をインストールしてログインする（`fly auth login`）
2. アプリを登録する：`fly launch --no-deploy --copy-config`（アプリ名は Fly 全体で重複できないため、`fly.toml` の `app` を変更する）
3. データ用の永続ボリュームを作る：`fly volumes create thecollapse_data --region nrt --size 1`
4. デプロイする：`fly deploy`

補足：
- 永続ボリュームは 1 台のマシンにしか付けられないため、台数を増やさないでください（チャットの状態もメモリ上にあります）。
- 既定では無通信時に停止し、アクセスで自動起動します。常時稼働にしたい場合は `fly.toml` の `min_machines_running` を `1` にします。
- チャット管理用のトークンなどを使う場合は `fly secrets set CHAT_ADMIN_TOKEN=...` で設定します。
- Fly.io の規約・無料枠・料金は変更されることがあります。利用前に公式の最新情報を確認してください。

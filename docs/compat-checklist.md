# サイト互換性チェックリスト

Ultraviolet移行（v1.0.11 → v3.2.10、将来的にScramjet）の各フェーズで
「動いていたサイトが動かなくなる」ことを防ぐための受入チェック。

## 使い方
- 各フェーズの作業後にこの表を埋め、**全項目○なら合格**（デフォルト切替などの次フェーズに進める）
- エンジン列: **v1 = /service/**（現行）・**v3 = /service3/**（フェーズ1で追加）
- △/× が一つでも出たらデフォルト切替は保留。そのサイトは旧エンジンで開く（サイト別フォールバックの対象にする）
- 記入日を「判定日」欄に残す（例: 2026-09-19）

## 判定基準
- ○: 問題なく使える
- △: 一部に不具合（メモに内容を書く）
- ×: ほぼ使えない

## テスト手順（サイトごとに同じ順で）
1. 普通に開く（シェルHTML・画像・アイコンが表示されるか）
2. ログインが必要なサイトはログイン → 再読み込み → ログインが維持されるか
3. 主要機能を実際に使う（X=タイムライン/ポスト表示、YouTube=動画再生、now.gg=ゲーム起動、momon-ga=閲覧+広告ブロックβ）
4. ページ内リンクを2〜3回遷移する
5. 再読み込み・戻る/進むが壊れないか
6. 30秒以上操作してエラーや読み込みスピンが出ないか

## フェーズ別の運用
- **フェーズ1（v3並行導入）**: v3列の初回記入。v1列も再確認して差分を残す
- **フェーズ2（デフォルト切替）**: v3列が全○の日の受入記録
- **フェーズ3（v1撤去）**: 撤去前に全サイトをv3で再チェック
